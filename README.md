# Venera 源 · 官方升级替换版

把官方源仓库里**版本落后**的源，替换成各第三方仓库维护的**最新版本**。

官方源仓库（`venera-app/venera-configs`）收录的 32 个源里，多个热门源长期不更新。
本仓库收录 **23 个有更高版本的源**，可直接替换。

## 订阅地址

```
https://raw.githubusercontent.com/lldaydayhappy/venera-sources/main/index.json
```

Venera → 仓库页 → 右上角 `+` → 填入上面的地址。

## 使用须知

### 1. `key` 保持不变

每个源的 `key` 与官方保持一致，替换后 Venera 会**原地更新**该源，
不会产生重复条目、不会丢失已保存的收藏。

### 2. 关于 `url` 字段

源文件里的 `url` 已全部改写指向本仓库。
这意味着 **Venera 的"检查更新"会从本仓库拉取**，不会被上游拉回旧版本。

### 3. 只收录"有升级"的源

官方那 9 个已是最高版本的源（如 mangabz、baozimh 等）**没有收录**，
避免与官方源重复。它们是互补关系，可同时订阅。

### 4. 关于站点探测（2026-09 实测）

用 curl 直接探测时，部分站点返回 `403 Just a moment...`、
`Attention Required! | Cloudflare`，这是 **Cloudflare 反爬挑战**，
**不代表源失效**——Venera 的 WebView 能正常通过。

以下源采用「API 域名 + 网页域名分离」设计，探测网页域名会 403 但 API 正常：

- 拷贝漫画 → API `api.copy-manga.com`（实测返回 `{"code":200,...}`）
- 优酷漫画 → API `m.ykmh.net`
- MYCOMIC → `mycomic.com`
- カドコミ → API `mobileapp.comic-walker.com`

另有 2 个源采用**多域名设计**（`goda.js`、`manhuaren.js`），
域名在设置里选择，源码中不硬编码。
